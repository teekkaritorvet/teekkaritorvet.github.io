# Teekkaritorvien esimerkkiohjelmistoa 

Täältä löydät esimerkkejä Teekkaritorvien ohjelmiston kappaleista. Näiden teemojen lisäksi valikoimistamme löytyy mm. jouluiseen juhlintaan sopivaa musiikkia, perinteisempää puhallinmusiikkia marsseineen ja paljon muutakin. Mahdollisuuksien mukaan toteutamme myös tilaajien erikoistoiveita! Ota yhteyttä, niin suunnitellaan musiikki juhliisi sopivaksi!
